## 📂 Project List

### 1. 🌏 Seismic Gap Indonesia *(International Journal Research)*

A full reproducible pipeline for spatiotemporal seismic gap analysis along the Indonesian subduction zone using KMeans clustering and LSTM-based forecasting.

* **Status:** Manuscript under review — *Computers & Geosciences*, Elsevier (IF 4.0, Q1)
* **Dataset:** 94,902 seismic events (M≥4.0, 1950–2026) — USGS + Masykuri et al. (2026)
* **Key Findings:**
  * 5 tectonic zones identified via KMeans (Silhouette = 0.3201)
  * 48 spatial seismic gaps detected; Maluku hazard score = 0.988 (Very High)
  * LSTM forecasting: best R² = 0.213 (Java-Bali-NTB), Pearson up to 0.74 (Sumatra)
* **Tech Stack:** Python, TensorFlow/Keras, scikit-learn, geopandas, pandas, matplotlib
* **Folder:** [`seismic-gap-indonesia/`](./seismic-gap-indonesia/)
